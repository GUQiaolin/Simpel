# Land-use parameters, one row per land use, including the phenology (LAI over the year) and the surface
# properties used by the PM method. The land use of a run is chosen with 'land_use = <name>' in run.txt;
# single values can be overridden there, e.g. land_use.max_lai = 3. To add a land use, add a row.
#
# Typical ranges (Central Europe, temperate climate), for orientation when choosing or overriding values.
# LAI is the one-sided green leaf area index; in winter it stands for the plant area (stems, branches,
# residues) that still intercepts rain. Root depth is the effective root depth of the soil water store,
# not the maximum depth of single roots.
#
#   land use             min_lai   max_lai   albedo      emissivity  veg_height (m)  root_depth (cm)
#   forest_deciduous     0.5-1.5   4-7       0.15-0.20   0.97-0.99   20-35           100-200
#   forest_evergreen     4-8       4-8       0.05-0.15   0.97-0.99   20-35           50-120 (spruce: shallow roots)
#   crop_corn            0-0.5     3-6       0.16-0.26   0.93-0.98   1.5-3.0         80-170
#   crop_sugarbeet       0-0.5     3-6       0.16-0.26   0.93-0.98   0.4-0.6         70-120
#   crop_winterwheat     0.3-1     4-7       0.16-0.26   0.93-0.98   0.8-1.2         100-180
#   grassland            0.5-1.5   2-6       0.16-0.26   0.93-0.98   0.1-0.5         30-100
#   grassland_irrigated  2-3       2-4       0.16-0.26   0.93-0.98   0.08-0.15       30-100
#   urban                0-1       0.1-2     0.05-0.40   0.85-0.98   5-20 (buildings) 1 (near-sealed, see below)
#
# Albedo and emissivity are the midpoints of the ranges for the land cover (evergreen 0.05-0.15 / 0.97-0.99,
# deciduous 0.15-0.20 / 0.97-0.99, grass and cropland 0.16-0.26 / 0.93-0.98, emissivity rounded to 0.95;
# urban: mean of asphalt 0.05-0.20 /
# 0.90-0.98, concrete 0.25-0.40 / 0.85-0.95 and roofs 0.08-0.35 / 0.90-0.95). They are static (no seasonal
# or snow albedo).
# Sources of the ranges: LAI after Asner et al. (2003) and Breuer et al. (2003); crop heights and root depths
# after FAO-56 (Allen et al. 1998, tables 12 and 22); grassland root depth after KA5 (arable value minus 2 dm
# or halved); spruce and beech root systems after forest-hydrology practice. Typical values, not site data.
#
# '-' = not given. What is needed follows from the components of the land use:
#   max_lai = 0          no canopy: icept_* not needed (ignored with a note)
#   min_lai = max_lai    constant LAI: the four phenology dates are not needed
#   min_lai < max_lai    phenology dates; '-' uses the default 121, 135, 305, 319 (1-15 May, 1-15 Nov)
#   litter_cap = 0       no litter layer: litter_reduction not needed
#   et_method = PM       albedo, emissivity and veg_height are required
#
# phenology
#   min_lai, max_lai        leaf area index outside / inside the growing season                     m2/m2
#   green_up_start, green_up_end, senescence_start, senescence_end
#                           days of the year, written for the northern hemisphere                    doy
# water balance
#   root_depth              depth of the soil water store (sets the size of the bucket)              cm
#                           above 0; for (nearly) sealed surfaces such as urban use a small value
#   degree_day              snow melt per degree above 0 degC                                         mm/degC/day
#   direct_runoff           share of the water passing the litter layer that runs off directly        %
#   litter_cap              storage capacity of the litter layer                                      mm
#   litter_reduction        litter drying factor: at most 1/factor of the water evaporates per day    -
#   icept_cap_per_lai       interception capacity per unit LAI (Rutter model)                         mm
#   icept_drain_b           drainage coefficient b of the interception store                          -
#   icept_drain_max         maximum drainage rate of the interception store                           mm/day
# surface (PM)
#   albedo, emissivity      of the surface                                                            -
#   veg_height              vegetation height, sets the roughness (static, also outside the season)   m
#
# Degree-day, direct runoff and litter capacity from the original SIMPEL land-use table (Hoermann);

# forest_deciduous and forest_evergreen use the SIMPEL values for beech and spruce).
